# n8n-Automation-Placement-Eligibility-Check  
🎓 **Automated Placement Eligibility Checker — n8n Workflow**

This repository contains a complete n8n workflow designed to automate the process of checking student placement eligibility based on course selection and academic performance.

## 🚀 Features
- Course selection (Data Science / Data Analytics)  
- Conditional branching using **Switch** and **IF** nodes  
- Automated marks collection through **n8n Forms**  
- Dynamic **average score calculation**  
- Eligibility verification using custom logic  
- Separate result pages for **Eligible / Not Eligible**  
- Fully **no-code** implementation  

---

## 🧠 Workflow Logic
1. Student selects a course  
2. Workflow routes to the respective marks form  
3. Marks are collected and averaged  
4. Eligibility criteria are applied based on course rules  
5. Student receives the final result

## 🧩 Technologies & Nodes Used
- n8n Forms 
- Switch Node  
- Code Node (average calculation)  
- IF / Condition Node
